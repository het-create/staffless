# STAFFLESS — License & Setup Agreement (Template)

⚠️ **This is a plain-language starting template, not a legal document.**
Before using this with a real paying client, have it reviewed by someone who
handles small-business agreements in your region — this template is meant to
save that person time, not replace them.

---

**Between:** [Your name / business name]
**And:** [Agency name]
**Date:** [Date]

## 1. What's being provided
[Your name] provides [Agency name] with a copy of the STAFFLESS software
("the Software"), consisting of the source code, setup documentation, and
[X hours] of setup support, in exchange for the fee described in Section 3.

## 2. What the Agency can do
- Run the Software internally, for its own client work
- Modify the Software for its own internal use
- Use outputs generated by the Software in real client deliverables

## 3. What the Agency cannot do
- Resell, sublicense, or redistribute the Software itself to third parties
- Rebrand and sell the Software as its own product
- Share the source code outside the Agency's own team

## 4. Fee
- One-time setup fee: ₹[amount]
- Optional ongoing support: ₹[amount]/month, covering [bug fixes / updates / X hours support]

## 5. Support & updates
[Describe what's included — e.g. "30 days of email support for setup issues"
or "no ongoing support beyond initial setup," whichever you're actually
offering.]

## 6. No warranty
The Software is provided as-is. [Your name] does not guarantee the AI-generated
output will be error-free, and the Agency is responsible for reviewing all
output before using it with its own clients.

## 7. Confidentiality
Client brief data entered into the Software by the Agency belongs to the
Agency and its clients; [Your name] does not access or store it once the
Software is handed over and running independently on the Agency's own
systems.
